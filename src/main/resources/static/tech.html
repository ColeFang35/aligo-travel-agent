五、关键组件拆解

🧭

意图识别与快/慢车道

IntentClassifier 句首锚定规则命中固定话术 → 快车道直达 conf=1.0；长句 → 慢车道两段式输出，拿不到 JSON 走 heuristic 兜底。approvalQuery 短路修复「查申请只出上海」bug。

🧩

子智能体装配 + 双模式模型

SubAgentFactory.build 按 agentKey 决定 Toolkit 与 sys prompt，实现能力+权限隔离；ModelFactory 用 ScriptedMockModel 离线演示，插 Key 切真模型，路径不变可回归。

🧠

上下文工程

SessionMemoryManager 三表（SessionRow/MsgRow/TurnRow），DynamicPromptStateMachine 按 COLLECT→PLAN→BOOK→DONE 动态拼 Prompt，PromptStore 存档审计。

🖥

全程可观测

FlowTracer start/end 记毫秒与 token，父子链由 MemoryStack 出入栈保证；TaskCollector 发布订阅推 task_update。debug → 火焰图/流程图/Prompt 快照/评测。

🎴

卡片协议 + 审批持久化

工具返回 _card JSON → TaskPrintHook 抽卡 → 前端 renderCard 分支渲染。ApprovalTool synchronized 落盘 approvals.json。

📚

RAG 知识注入

KnowledgeBaseService 模拟 MaxKB 检索差旅报销标准，返回 kb 卡片引用来源；query 改写，可换真向量库。

六、面试 / 答辩高频追问

哪些是你自己写的？
编排层+业务工具+三表记忆+FlowTracer 观测+审批持久化；Agent 循环/事件/Toolkit/Middleware 全是 AgentScope API。
为什么用 SSE 不用 WebSocket？
Agent 是「问一句回一串」单向流，SSE 更简单、自动重连、易过代理。
火焰图是假的吗？
每次调用 start/end 计时+token，父子链由 MemoryStack 出入栈维护，与真实调用一一对应。
Mock 模型有意义吗？
只换模型实现，编排/工具/观测路径一致，低成本回归，插 Key 切真模型。
1000 并发扛得住吗？
现为单线程 worker+内存，演示够用；生产换线程池+Redis+DB 事务+限流降级。
怎么加一个新工具？
写返回 _card 的方法加 @Tool，toolkitFor 注册对应 agentKey，前端 renderCard 加分支。
两分钟讲稿：意图快慢车道 → SubAgentFactory 装配 → ReActAgent 执行 → 工具返回 _card → TaskPrintHook 抽卡 → SSE 流 → FlowTracer 全程观测。核心论点：先查文档、复用框架、只写编排。
